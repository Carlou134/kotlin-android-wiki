# Glosario

Las palabras que aparecen en las lecciones de esta carpeta, explicadas de forma simple. Están en orden alfabético.

-----

**Asignación aumentada.** Operador que calcula y reasigna en un paso, como `+=` o `-=`.

**camelCase.** Convención de nombres: primera palabra en minúscula y las siguientes con mayúscula inicial, como `guitarName`.

**`Char`.** Tipo que guarda un solo carácter entre comillas simples, como `'a'`.

**Concatenación.** Unir dos o más `String` con el operador `+`.

**Decimal (punto flotante).** Número con parte decimal. En Kotlin: `Float` y `Double`.

**Entero.** Número sin parte decimal. En Kotlin: `Byte`, `Short`, `Int` y `Long`.

**Incremento / decremento.** Operadores `++` y `--`, que suman o restan 1 a una variable.

**Inferencia de tipos.** Capacidad del compilador de deducir el tipo de una variable a partir de su valor, sin que lo escribas.

**Inmutable (`val`).** Variable cuyo valor no puede reasignarse después de inicializarla.

**Módulo (`%`).** Operador que devuelve el resto de una división. Útil para saber si un número es par.

**Mutable (`var`).** Variable cuyo valor puede cambiar a lo largo del programa.

**Operador aritmético.** Símbolo para calcular: `+`, `-`, `*`, `/` y `%`.

**Plantilla de cadena (string template).** Forma de insertar el valor de una variable dentro de un texto con `$`, como `"Hola, $nombre"`.

**`readLine()`.** Función que espera a que el usuario escriba en la consola y devuelve lo escrito como texto.

**Secuencia de escape.** Combinación que empieza con `\` y da formato dentro de un texto, como `\n` (salto de línea).

**`String`.** Tipo que guarda una secuencia de caracteres entre comillas dobles.

**Tipo de dato.** Qué clase de valor guarda una variable (`String`, `Int`, `Boolean`...) y qué operaciones admite.

**Variable.** Nombre que guarda un valor para usarlo más adelante en el programa.
