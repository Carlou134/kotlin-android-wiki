# Glosario

Las palabras que aparecen en las lecciones de esta carpeta, explicadas de forma simple. Están en orden alfabético.

-----

**Aserción no nula (`!!`).** Operador que obliga a tratar un valor nulable como no nulo. Si el valor es `null`, lanza `NullPointerException`.

**Excepción.** Error que ocurre mientras el programa se ejecuta. Si nadie la captura, el programa se detiene.

**Excepción personalizada.** Clase propia que hereda de `Exception` para representar un error de tu dominio.

**Llamada segura (`?.`).** Accede a una propiedad o función solo si el valor no es `null`; si lo es, devuelve `null`.

**`null`.** Ausencia de valor.

**NullPointerException.** Error que ocurre al intentar usar un valor `null` como si existiera.

**Operador Elvis (`?:`).** Devuelve el valor de la izquierda si no es `null`, o el de la derecha si lo es.

**`throw`.** Palabra clave para lanzar una excepción.

**Tipo nulable.** Tipo terminado en `?` (como `String?`) que acepta `null`.

**`try` / `catch` / `finally`.** `try` envuelve el código que puede fallar, `catch` maneja la excepción y `finally` se ejecuta siempre.
