# Glosario

Las palabras que aparecen en las lecciones de esta carpeta, explicadas de forma simple. Están en orden alfabético.

-----

**Breakpoint.** Punto del código donde el programa se pausa en modo Debug para que inspecciones las variables.

**Bug.** Error que hace que el programa se comporte de forma inesperada.

**Bytecode.** Instrucciones intermedias (archivos `.class`) que genera el compilador y que entiende la JVM.

**Comentario.** Texto dentro del código que el compilador ignora. Sirve para explicar: `//` para una línea y `/* */` para varias.

**Compilador.** Programa que revisa tu código y lo traduce a instrucciones que la computadora puede ejecutar.

**Gradle.** Herramienta que gestiona las dependencias y la compilación de un proyecto.

**IDE.** Entorno de desarrollo: editor con herramientas para escribir, ejecutar y depurar código.

**`.jar`.** Archivo que empaqueta muchos archivos compilados en uno solo, listo para ejecutarse con `java -jar`.

**JDK.** Kit de desarrollo de Java. Todo proyecto Kotlin para la JVM necesita uno para compilar y ejecutar.

**JVM (Java Virtual Machine).** Programa que ejecuta el bytecode. No entiende Kotlin, solo bytecode.

**`kotlinc`.** El compilador de Kotlin para usar desde la terminal.

**`main()`.** Función donde empieza todo programa Kotlin.

**Tipado estático.** Los tipos se verifican al compilar, antes de ejecutar. Por eso muchos errores aparecen sin correr el programa.
