# Glosario

Las palabras que aparecen en las lecciones de esta carpeta, explicadas de forma simple. Están en orden alfabético.

-----

**Array.** Colección de tamaño fijo creada con `arrayOf`. Puedes cambiar sus elementos, pero no agregar ni quitar.

**Clave (key).** Identificador único de una entrada en un map.

**Colección.** Grupo de elementos guardados en una sola estructura: listas, sets y maps.

**`elementAt()`.** Función que devuelve el elemento de un set en una posición. `elementAtOrNull()` devuelve `null` si esa posición no existe.

**Entrada (entry).** Un par clave-valor dentro de un map.

**Índice.** Posición de un elemento en una lista. Empieza en 0.

**Lista.** Colección ordenada que admite elementos repetidos.

**Map (mapa).** Colección de pares clave-valor donde cada clave es única.

**Set (conjunto).** Colección de elementos únicos: no admite duplicados.

**Solo lectura / modificable.** Una colección creada con `xxxOf` no se puede cambiar; una creada con `mutableXxxOf` sí.

**`to`.** Palabra que une una clave con su valor al crear un map: `"ana" to 30`.

**Valor (value).** Dato asociado a una clave en un map. Los valores sí pueden repetirse.
